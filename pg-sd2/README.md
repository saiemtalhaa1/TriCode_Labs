# OutfitShare (TriCode Labs)

A community-based platform where **students and local residents** can **lend and borrow outfits** for job interviews and special occasions — reducing cost and clothing waste while building community connections.

---

## Problem
Many people need formal outfits for interviews/events but do not want to buy expensive clothing for one-time use. At the same time, many community members own outfits that are rarely used.

## Target users
- University students  
- Local community members

## What can be shared
- Suits / blazers
- Dresses
- Shoes
- Accessories (ties, belts, bags)
- Shared essentials (jackets/coats, formal shirts)

## MVP features (Sprint scope)
- Create an account and profile
- Create an outfit listing (**category, size, condition, description, photos, availability**)
- Browse and filter listings (**by category, size, tags**)
- Request to borrow an item (**up to 7 days**)
- Lender can **accept / decline** requests
- Status tracking: **pending, accepted, declined, returned**
- Dashboards: **My Listings** and **My Requests**

## Borrow duration policy
- Standard lending period: **7 days**
- Optional extension: up to **14 days**, with lender approval
- **No payments in MVP** (to keep it simple and community-focused). Payments/fees can be considered later.

## Constraints (to keep the project achievable)
- No payments
- No deliveries/shipping
- No complex identity verification

## Safety (high level)
- Handovers should occur in **safe public locations** (e.g., university campus / public area)
- Avoid publicly sharing personal addresses/phone numbers
